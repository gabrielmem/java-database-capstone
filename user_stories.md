# User Stories
**As an Admin, I want** to log into the portal so that I can manage the platform securely.
**As an Admin, I want** to add and delete doctors so that the clinic roster is up-to-date.
**As a Doctor, I want** to view my appointment calendar so that I stay organized.
**As a Doctor, I want** to mark my unavailability so that patients only see valid slots.
**As a Patient, I want** to sign up and log in so that I can book appointments.
